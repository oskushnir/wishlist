# Wishlist Application 📝

Це простий вебзастосунок для керування особистим списком бажань (Wishlist). Він дозволяє користувачам додавати, переглядати, оновлювати, видаляти та фільтрувати свої бажання.

## ✨ Основні можливості

* **Повний CRUD:** Додавання, перегляд, редагування та видалення бажань.
* **Детальний перегляд:** Окрема сторінка для кожного бажання.
* **Сортування та Фільтрація:** Можливість сортувати список бажань за датою або ціною.
* **Сповіщення:** Інтерактивні сповіщення (toasts) про стан операцій (завантаження, успіх, помилка).
* **Адаптивний дизайн:** Коректно відображається на десктопах та мобільних пристроях.

---

## 🛠️ Технології

* **React** (з використанням React Hooks)
* **TypeScript**
* **Vite** (збірник проєкту)
* **React Router** (для навігації та окремих сторінок)
* **Tailwind CSS** (для стилізації)
* **shadcn/ui** (компоненти інтерфейсу, такі як `Modal`, `Skeleton`, `Button`)
* **Sonner** (для сповіщень)

## 🚀 Як запустити локально

Ось покрокова інструкція для запуску проєкту на вашому комп'ютері.

### Передумови

Перед початком переконайтеся, що у вас встановлено:
* [Node.js](https://nodejs.org/) (рекомендована версія v18 або новіша)
* [npm](https://www.npmjs.com/) (зазвичай встановлюється разом з Node.js)

### Крок 1: Клонування репозиторію

Спочатку склонуйте репозиторій на свій комп'ютер та перейдіть у його директорію:

```bash
git clone [https://your-repository-url.git](https://your-repository-url.git)
cd your-project-directory-name
```

### Крок 2: Встановлення залежностей

Встановіть усі необхідні npm пакети, які вказані у package.json

```bash
npm install
```

### Крок 3: Запуск Mock API (json-server)

Цей проєкт використовує json-server для імітації бекенду.

Переконайтеся, що у вас в кореневій папці проєкту є файл db.json.

Відкрийте окремий термінал та запустіть json-server

```bash
npx json-server db.json
```

Це запустить mock API-сервер, зазвичай за адресою http://localhost:3000. Залиште цей термінал працюючим.

### Крок 4: Запуск проєкту

Відкрийте новий (другий) термінал (не той, де запущено json-server).

Виконайте команду

```bash
npm run dev
```

Це запустить застосунок у режимі розробки. Відкрийте ваш браузер та перейдіть за адресою, яку побачите у терміналі (зазвичай це http://localhost:5173).
